# Changelog

## v1.0.0 - 2026-07-08

- Added loading, previewing, reordering, and removing Eagle selected items.
- Added pattern rename, text replacement, prefix/suffix, positional insert, and positional delete.
- Added number and letter sequences, start value, step value, and zero padding.
- Added safety checks for duplicate names, illegal characters, empty names, trailing spaces/dots, and name length.
- Added adaptive batch saving, item-level progress display, and task stop confirmation.
- Added Synology Drive and Windows naming risk audit with batch import for risky items.
- Added English, Simplified Chinese, and Traditional Chinese localization.
- Added Eagle theme-aware styling.
