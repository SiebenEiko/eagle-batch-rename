# Privacy Policy

Batch Rename runs locally inside Eagle.

## Data Access

The plugin reads Eagle item metadata required for rename preview, validation, and saving. This can include item names, extensions, IDs, folders, and paths available through the Eagle Plugin API.

## Data Storage

The plugin does not send item data to an external server and does not include analytics, tracking, advertising, or telemetry.

The plugin does not store a remote copy of the user's library, names, or paths.

## Network

The plugin does not require network access for its rename and audit features.

## User Control

Rename operations are previewed before saving. If the user stops a running task, already saved items are not rolled back and unprocessed items keep their original names.
